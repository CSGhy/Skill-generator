# 测试报告生成器

这个skill专注于根据测试执行结果生成专业的测试报告，包括测试概述、测试结果、缺陷统计、风险评估等内容。

## 📋 快速参考卡片

### 基本指令格式

```
/test-case-report-generator [测试结果] [选项]
```

#### 参数说明

**必填参数**：
- `test-results`：测试执行结果（必填）

**可选参数**：
- `--project-info`：项目信息，格式：`项目名称,版本,环境`（默认：自动提取）
- `--report-format`：报告格式，可选值：`md`|`html`|`word`|`pdf`（默认：`md`）
- `--include-charts`：是否包含图表，可选值：`true`|`false`（默认：`true`）
- `--include-trends`：是否包含趋势分析，可选值：`true`|`false`（默认：`false`）

#### 参数Schema

```json
{
  "test-results": {
    "type": "string",
    "minLength": 1,
    "description": "测试执行结果"
  },
  "project-info": {
    "type": "string",
    "description": "项目信息，格式：项目名称,版本,环境"
  },
  "report-format": {
    "type": "string",
    "enum": ["md", "html", "word", "pdf"],
    "default": "md",
    "description": "报告格式"
  },
  "include-charts": {
    "type": "boolean",
    "default": true,
    "description": "是否包含图表"
  },
  "include-trends": {
    "type": "boolean",
    "default": false,
    "description": "是否包含趋势分析"
  }
}
```

## 数据分析

### 测试通过率分析

#### 计算公式
```
测试通过率 = (通过用例数 / 总用例数) × 100%
```

#### 评价标准
| 通过率 | 评价 | 建议 |
|-------|------|------|
| ≥ 95% | 优秀 | 可以发布 |
| 90%-94% | 良好 | 建议修复后发布 |
| 80%-89% | 合格 | 需要修复主要缺陷 |
| < 80% | 不合格 | 需要重新测试 |

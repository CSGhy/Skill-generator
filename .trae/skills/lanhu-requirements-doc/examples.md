# 蓝湖需求文档生成器 - 使用示例

## 示例1：基础使用

### 场景
生成一个简单的登录功能需求文档

### 输入指令
```
/lanhu-requirements-doc https://lanhuapp.com/project/12345
```

### 预期输出
```markdown
# 需求文档：用户登录功能

## 需求基本信息
- **原型名称**：用户登录功能
- **蓝湖链接**：https://lanhuapp.com/project/12345
- **适用模块**：用户模块
- **版本**：v1.0
- **创建时间**：2024-01-01

## 需求背景
本项目旨在为用户提供安全、便捷的登录功能，支持多种登录方式，确保用户数据安全。

## 核心功能模块

### 1. 登录页面
- **功能描述**：用户登录入口
- **优先级**：P0
- **依赖模块**：无

### 2. 注册页面
- **功能描述**：新用户注册
- **优先级**：P1
- **依赖模块**：登录页面

## 页面交互逻辑

### 登录页面
1. 用户输入用户名和密码
2. 点击"登录"按钮
3. 系统验证用户信息
4. 验证成功，跳转到首页
5. 验证失败，显示错误提示

### 注册页面
1. 用户点击"注册"链接
2. 跳转到注册页面
3. 用户填写注册信息
4. 点击"提交"按钮
5. 系统验证注册信息
6. 注册成功，跳转到登录页面

## UI元素说明

### 登录页面布局
- 顶部：Logo和标题
- 中间：用户名输入框、密码输入框、登录按钮
- 底部：注册链接、忘记密码链接

### 组件说明
- **用户名输入框**：文本输入，最大长度50字符
- **密码输入框**：密码输入，显示为星号
- **登录按钮**：主按钮，点击触发登录

## 数据规则

### 输入格式要求
- **用户名**：4-50字符，支持字母、数字、下划线
- **密码**：8-20字符，必须包含字母和数字

### 数据验证规则
- 用户名不能为空
- 密码不能为空
- 用户名格式必须符合要求
- 密码格式必须符合要求

## 特殊约束

### 权限限制
- 所有用户均可访问登录页面
- 已登录用户无法访问登录页面

### 性能要求
- 登录响应时间 < 2秒
- 页面加载时间 < 1秒

### 兼容性要求
- 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- 支持移动端浏览器

### 安全性要求
- 密码必须加密传输
- 防止SQL注入
- 防止XSS攻击

## 异常处理

### 异常场景
1. 用户名或密码错误
2. 网络连接失败
3. 服务器错误
4. 账号被锁定

### 错误提示
- 用户名或密码错误："用户名或密码错误，请重试"
- 网络连接失败："网络连接失败，请检查网络"
- 服务器错误："服务器错误，请稍后重试"
- 账号被锁定："账号已被锁定，请联系管理员"

### 恢复机制
- 用户名或密码错误：允许重试，最多5次
- 网络连接失败：提供重试按钮
- 服务器错误：自动重试，最多3次
- 账号被锁定：提供联系管理员入口
```

## 示例2：指定模块生成

### 场景
生成购物车模块的需求文档

### 输入指令
```
/lanhu-requirements-doc https://lanhuapp.com/project/12345?module=shopping-cart
```

### 预期输出
```markdown
# 需求文档：购物车功能

## 需求基本信息
- **原型名称**：购物车功能
- **蓝湖链接**：https://lanhuapp.com/project/12345?module=shopping-cart
- **适用模块**：购物车模块
- **版本**：v1.0
- **创建时间**：2024-01-01

## 需求背景
购物车功能是电商平台的核心功能，允许用户添加商品、修改数量、删除商品、结算等操作。

## 核心功能模块

### 1. 购物车列表
- **功能描述**：展示购物车中的商品
- **优先级**：P0
- **依赖模块**：商品模块

### 2. 商品数量修改
- **功能描述**：修改购物车中商品数量
- **优先级**：P1
- **依赖模块**：购物车列表

### 3. 商品删除
- **功能描述**：从购物车中删除商品
- **优先级**：P1
- **依赖模块**：购物车列表

### 4. 结算功能
- **功能描述**：购物车结算
- **优先级**：P0
- **依赖模块**：购物车列表、订单模块

## 页面交互逻辑

### 购物车列表
1. 用户进入购物车页面
2. 系统展示购物车中的商品
3. 用户可以修改商品数量
4. 用户可以删除商品
5. 用户可以点击结算按钮

### 商品数量修改
1. 用户点击"+"或"-"按钮
2. 系统更新商品数量
3. 系统重新计算总价
4. 系统更新库存信息

### 商品删除
1. 用户点击删除按钮
2. 系统弹出确认对话框
3. 用户确认删除
4. 系统从购物车中删除商品
5. 系统重新计算总价

### 结算功能
1. 用户点击结算按钮
2. 系统跳转到结算页面
3. 用户填写收货地址
4. 用户选择支付方式
5. 用户确认订单
6. 系统创建订单
7. 系统跳转到支付页面

## UI元素说明

### 购物车页面布局
- 顶部：页面标题、全选按钮、删除按钮
- 中间：商品列表
- 底部：总价、结算按钮

### 组件说明
- **商品卡片**：展示商品信息、数量、价格
- **数量选择器**：增加、减少、输入数量
- **删除按钮**：删除商品
- **全选按钮**：全选/取消全选
- **结算按钮**：跳转到结算页面

## 数据规则

### 输入格式要求
- **商品数量**：1-999的正整数

### 数据验证规则
- 商品数量不能为空
- 商品数量必须为正整数
- 商品数量不能超过库存

### 数据计算规则
- 单品总价 = 商品单价 × 商品数量
- 购物车总价 = 所有商品总价之和

## 特殊约束

### 权限限制
- 仅登录用户可访问购物车
- 仅本人可查看自己的购物车

### 性能要求
- 购物车加载时间 < 1秒
- 商品数量更新响应时间 < 500ms

### 兼容性要求
- 支持主流浏览器
- 支持移动端浏览器

### 安全性要求
- 防止价格篡改
- 防止库存超卖
- 防止重复提交

## 异常处理

### 异常场景
1. 购物车为空
2. 商品库存不足
3. 商品已下架
4. 网络连接失败

### 错误提示
- 购物车为空："购物车为空，快去选购商品吧"
- 商品库存不足："商品库存不足"
- 商品已下架："商品已下架"
- 网络连接失败："网络连接失败，请检查网络"

### 恢复机制
- 购物车为空：引导用户去商品列表
- 商品库存不足：提示用户减少数量或删除商品
- 商品已下架：自动从购物车中删除商品
- 网络连接失败：提供重试按钮
```

- 页面命名不规范

### 问题3：无法连接蓝湖MCP

**可能原因**：
- MCP服务未启动
- MCP配置错误
- 网络连接问题
- API密钥无效

**解决方案**：
1. 检查MCP服务状态
2. 检查MCP配置

- MCP性能问题

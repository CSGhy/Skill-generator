# 蓝湖需求文档生成器

## 概述

蓝湖需求文档生成器是一个专门用于从蓝湖平台自动拉取原型数据并生成标准化需求文档的AI辅助工具。该Skill能够根据用户提供的蓝湖链接，自动调用蓝湖MCP（Model Context Protocol）拉取PRD、产品原型或UI设计内容，一键输出结构化、标准化的Markdown需求文档。

## 核心能力

### 1. 自动拉取，告别手动复制
- 无需逐页截图、复制原型标注
- 直接通过指令调用蓝湖MCP
- 完整读取蓝湖上的原型页面、交互逻辑、备注说明

### 2. 标准化输出，格式统一
- 自动将零散的原型信息整理为Markdown格式
- 包含需求背景、核心功能、交互说明、特殊约束等固定模块
- 规避人工整理的格式混乱问题

### 3. 无缝衔接后续测试工作
- 生成的标准化需求文档可直接作为AI输入
- 快速开展测试提案生成、需求分析、用例设计等工作
- 打通"需求梳理→测试设计"全流程

## 使用前提

在使用该Skill前，需确保以下条件已满足：

1. **蓝湖MCP已安装并正常启动**
   - MCP是实现Skill与蓝湖平台数据互通的核心
   - 若未安装或启动失败，Skill将无法读取蓝湖原型内容
   - 详见[MCP配置指南](#mcp配置指南)

2. **蓝湖平台访问权限**
   - 确保对目标蓝湖项目有访问权限
   - 确保蓝湖链接有效且可访问
   - 建议使用项目成员账号

3. **网络连接正常**
   - 确保能够访问蓝湖平台
   - 确保MCP服务可正常通信
   - 建议使用稳定的网络环境

4. **蓝湖项目规范**
   - 确保蓝湖项目结构清晰
   - 确保页面命名规范
   - 确保备注信息完整

## 使用方法

### 基本指令格式

```
/lanhu-requirements-doc [蓝湖链接] [选项]
```

#### 参数说明

**必填参数**：
- `url`：蓝湖项目或页面链接（必填）

**可选参数**：
- `--format`：输出格式，可选值：`md`|`html`|`pdf`|`docx`|`xlsx`（默认：`md`）
- `--version`：指定版本（默认：最新版本）
- `--template`：自定义模板文件路径（默认：内置模板）
- `--output`：输出文件路径（默认：当前目录）
- `--analyze`：启用智能分析（默认：`false`）
- `--compare`：版本对比，格式：`v1.0,v2.0`（默认：不对比）
- `--batch`：批量处理文件路径（默认：不批量）

### 详细操作步骤

#### 步骤1：准备蓝湖链接
- 打开蓝湖平台
- 找到需要解析的原型项目
- 复制项目链接或页面链接

#### 步骤2：输入指令
在支持的AI编辑器（如Cursor、Trae）中输入：

```
/lanhu-requirements-doc https://lanhuapp.com/xxxxx
```

#### 步骤3：等待解析
- AI会自动调用已启动的蓝湖MCP
- 向蓝湖平台发起请求
- 读取对应原型的所有内容，包括：
  - 页面布局
  - 按钮交互
  - 输入框规则
  - 备注信息

#### 步骤4：获取文档
等待解析完成后，AI会自动将读取到的原型信息进行结构化整理，生成完整的Markdown格式需求文档。

## MCP配置指南

### 什么是MCP

MCP（Model Context Protocol）是一种标准化的协议，用于AI模型与外部数据源通信。蓝湖MCP实现了Skill与蓝湖平台之间的数据互通。

### 安装蓝湖MCP

#### 步骤1：获取MCP安装包

1. 访问蓝湖官方MCP仓库
2. 下载最新版本的蓝湖MCP
3. 解压安装包到本地目录

#### 步骤2：配置MCP

1. 打开MCP配置文件（通常是`config.json`）
2. 配置蓝湖API密钥：
   ```json
   {
     "lanhu": {
       "api_key": "your_api_key_here",
       "base_url": "https://api.lanhuapp.com"
     }
   }
   ```
3. 保存配置文件

#### 步骤3：启动MCP服务

```bash
# 进入MCP目录
cd lanhu-mcp

# 启动MCP服务
python main.py

# 或者使用PM2管理
pm2 start lanhu-mcp --name lanhu-mcp
```

#### 步骤4：验证MCP服务

```bash
# 检查MCP服务状态
curl http://localhost:3000/health

# 或者查看日志
pm2 logs lanhu-mcp
```

### MCP配置优化

#### 性能优化

1. **启用缓存**
   ```json
   {
     "cache": {
       "enabled": true,
       "ttl": 3600
     }
   }
   ```

2. **并发请求**
   ```json
   {
     "concurrency": {
       "max": 10
     }
   }
   ```

3. **超时设置**
   ```json
   {
     "timeout": {
       "connect": 5000,
       "read": 30000
     }
   }
   ```

#### 安全优化

1. **API密钥加密**
   - 使用环境变量存储API密钥
   - 不要在配置文件中明文存储

2. **访问控制**
   - 限制MCP服务的访问IP
   - 使用HTTPS加密传输

3. **日志脱敏**
   - 不要记录敏感信息
   - 定期清理日志

```

详细信息：

可能原因：
1. 链接格式错误
2. 链接不完整
3. 使用了错误的协议

解决建议：
1. 检查链接是否以 https:// 开头
2. 确认链接是否完整
3. 从蓝湖平台重新复制链接
```

#### 错误2：蓝湖MCP未启动

**错误信息**：
```
❌ 错误：无法连接到蓝湖MCP服务

详细信息：
- MCP服务地址：{{mcp_url}}
- 连接超时：5秒

可能原因：
1. MCP服务未启动
2. MCP服务地址配置错误

解决建议：

可能原因：

# 加载工具：lanhu-requirements-doc, validate-lanhu-url, convert-document-format

用户：生成用户登录功能需求文档
满意度：4分
需求文档质量：5分
是否需要调整：否
调整建议：无
```

### 反馈分析
- 平均满意度：4.2分
- 平均需求文档质量：4.5分
- 调整率：15%
- 常见问题：缺少异常处理说明

### 进化策略
基于用户反馈，系统会自动决定进化策略：
- **MERGE**：当满意度>4.5分时，合并优化，版本号+1
- **ADD**：当满意度3.0-4.5分时，添加新能力，补丁号+1
- **DISCARD**：当满意度<3.0分时，标记为需要重构
